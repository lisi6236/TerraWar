## 2. 需求基线（已确认）

1. 时间模型：**回合制 + 同时结算**（各国同时提交指令 → 统一结算）。
2. 首版（MVP）即含：陆军 / 海军 / 空军 / 外交 / 补给线 / 自动战斗 / 征服胜利判定。
3. 地图：**可选**，首张默认 **欧洲**。
4. 地块：省份多边形，取自**真实地理边界**（Natural Earth 行政区划）。
5. 规模：3 国≈30 省，5 国≈50 省，7 国≈70 省；每国开局 5~6 省，其余为**空白未占领区**（扩张目标）。
6. 玩家**随机**分配到某一国家。
7. 美术：**写实俯视地形 + 政治填色**，程序化绘制，必要时 AI 生图做贴图。
8. 前端 React + TS + Vite（地图 SVG 起步）；后端 Node + TS；**账号登录**；**本地存档**（暂不做云存档）。
9. 部署：本地开发 + 可自托管。
10. 界面中文；代码英文 / 注释中文 / 文档中文。
11. 仓库：https://github.com/lisi6236/TerraWar.git （目前为空）

## 5. 数据模型与格式

### 5.1 地图（GeoJSON + 附加属性）
每个 feature = 一个地块（省 / 海域）。

```json
{
  "type": "Feature",
  "properties": {
    "id": "fr_idf",
    "name": "法兰西岛",
    "kind": "land",                 // land | sea | strait | canal
    "terrain": "plain",             // plain|hills|mountain|forest|desert|urban|coast
    "isCapital": true,
    "isCore": false,                // 核心资源区
    "isChoke": false,               // 山口要道 / 海峡
    "base": { "steel": 3, "oil": 1, "food": 4, "fund": 6 },
    "population": 120,
    "defenseBonus": 1.0,
    "adjacency": ["fr_nor", "fr_ges"],
    "ownerAtStart": "FR",           // 开局归属（null = 空白未占领）
    "seaZone": null
  },
  "geometry": { "type": "Polygon", "coordinates": [[[0, 0]]] }
}
```

- **相邻关系**：由 mapgen 依据"共享边界"离线计算并写入 `adjacency`（保证确定性与性能）。
- 海域按**真实海区**切分为若干 `kind: "sea"` 地块，含 `strait`（海峡）。

### 5.2 国家

```ts
interface Nation {
  id: string; name: string; color: string;
  capital: ProvinceId;
  personality: {
    aggression: number;      // 野心 0~1
    cooperativeness: number; // 亲善 0~1
    expansionism: number;    // 扩张倾向 0~1
    riskTolerance: number;   // 冒险 0~1
    loyalty: number;         // 守约倾向 0~1
  };
  resources: { steel: number; oil: number; food: number; fund: number };
  reputation: number;                  // 外交信誉 0~100
  relations: Record<NationId, number>; // -100~100
  treaties: TreatyState[];
  tech: { era: Era; unlocked: string[] };
  isPlayer: boolean;
  alive: boolean;
}
```

### 5.3 单位

```ts
interface Unit {
  id: string; type: UnitType; owner: NationId; province: ProvinceId;
  strength: number;      // 当前战力（满编 = 基础战力）
  maxStrength: number;
  morale: number;        // 0~100
  supply: "ok" | "low" | "cut";
  general?: { name: string; level: "mediocre" | "excellent" | "legendary" };
  cargo?: UnitId[];      // 运输舰队搭载的陆军
  movedThisTurn: number;
  entrenchedTurns: number;
}
```

### 5.4 存档

```ts
interface SaveGame {
  version: number; seed: number;
  mapId: string; mapHash: string;
  turn: number; phase: "orders" | "resolve";
  nations: Nation[];
  provinces: ProvinceRuntime[];
  units: Unit[];
  diplomacy: DiplomacyState;
  orders: Order[];        // 当前回合待结算指令
  log: LogEntry[];        // 战报 / 事件日志
  createdAt: string; updatedAt: string;
}
```

- 存档带 `version` + **迁移函数**，保证旧档在后续版本仍可读取（对长期开发友好）。

## 6. 核心系统设计

### 6.1 回合流程（同时结算）

每个回合分两阶段：

**A. 指令阶段**：玩家下达指令（移动 / 进攻 / 建造 / 外交 / 招募 / 科研）；AI 各自生成指令。玩家点「结束回合」。

**B. 结算阶段**（固定顺序，保证确定性）：
1. 外交结算：条约签订 / 生效 / 到期 / （选择）撕毁生效，关系与信誉更新。
2. 科研 / 建造 / 动员推进。
3. 移动与冲突裁决（§6.2）。
4. 战斗结算（§6.3，复用文档公式）。
5. 占领与抵抗值更新。
6. 补给线重算（§6.4）。
7. 士气结算。
8. 资源产出与消耗、维护费。
9. 迷雾与侦察更新。
10. 胜利判定（§6.9）。

→ 进入下一回合。

### 6.2 冲突裁决规则（📌 文档缺失，草案待确认）

原文档只给战斗公式，没规定「同一地块被多方同时进入」如何处理。草案：

1. **不允许借道**：单位进入任一地块即视为进入 / 交战，不会"穿过"敌方单位。
2. **同地块多方混战**：若某地块有多国军队同时进入——
   - 若该地块有守军：守军与全部来犯方先打一场「会战」；来犯方合计战力 vs 守军战力，按战力占比分摊双方战损。
   - 守军被击溃（或本无守军）后：进入该地块的**战力最高**的来犯方占领该地块，其余来犯方退回出发地块。
3. **互相交换地块**（A 从 X 打 Y、B 从 Y 打 X）：双方同时面对对方**留守**兵力；若守方已离开（无守军），双方各自占领目标地块（即完成交换）。
4. **多格移动**：陆军 1 格 / 海军 2 格；多格移动中若中途遇敌，就地停下战斗。
5. **平局判定**：按（现有战力 → 士气 → 座次 / 玩家优先）依次比较，保证确定性。

> 目标：**确定性 + 直觉合理**，不引入随机；数值可调。

### 6.3 战斗结算

完全复用 `战斗结算公式与数值规则.md`：

```
最终战力 = 基础 × 地形修正 × 设施修正 × 补给修正 × 制空修正 × 士气修正 × 包围修正 × 将领修正
```

战损率与胜负判定照文档。引擎实现为**纯函数**：输入双方快照 → 输出战损 / 结果，便于单测与平衡调参。

### 6.4 补给线

- 每回合从单位所在地块做 BFS/Dijkstra，经由「己方或同盟控制的陆地 / 海上地块」连通到本国首都 / 补给节点。
- 结果分级：正常 / 不足 / 断绝（对应战力 ×1.0 / 0.7 / 0.4 与士气扣减，照文档）。
- 海军：以己方港口为补给源；空军：以驻机场所在补给网为准。

### 6.5 外交系统

- 关系值（-100~100，5 档）、信誉（0~100）、条约状态机（每类条约的生效条件 / 有效期 / 违约惩罚，照文档）。
- 秘密外交：对 AI 模拟「私聊 / 秘密条约」，含暴露概率（照文档）与暴露惩罚。
- AI 外交决策由 §6.7 的个性驱动。

### 6.6 内政与经济

- 资源：钢铁 / 石油 / 粮食 / 资金（产出见 §7）；单位维护费、建造 / 科研消耗。
- 建造：公路 / 机场 / 港口 / 要塞（逐级升级）。
- 科技时代：一战 → 二战 → 冷战 → 现代，逐时代解锁兵种 / 设施 / 战术。
- 动员：常备军 + 预备役；动员 3~5 回合，期间地块产出下降，规模受人口限制。

### 6.7 AI 设计

- 每个 AI 国家一套**个性参数**（见 §5.2）：野心 / 亲善 / 扩张 / 冒险 / 守约。
- 简单 AI 决策循环（每回合）：
  1. 评估周边：空白省（扩张价值）/ 敌省（进攻价值）/ 己省防御薄弱点。
  2. 按个性决定：进攻 / 囤积 / 建交 / 签约 / 背刺。
  3. 外交：按 cooperativeness / loyalty 提议或接受条约；按 aggression 撕毁 / 宣战。
  4. 资源分配：军队 / 建筑 / 科研的预算比例。
- 首版「简单 AI」= 规则 + 权重，不含搜索 / 学习；架构预留后续增强（行为树 / 效用 AI）。

### 6.8 迷雾与侦察

照文档：未侦察显示兵力档位；陆军侦察 / 空军侦察 / 同盟共享 / 情报窃取。

### 6.9 胜利条件

- **首版仅实现征服胜利**（占领所有敌对国首都 / 消灭敌对势力）并做失败判定（首都丢失 > 10 回合等，照文档）。
- 其余三类（外交 / 经济 / 地缘）预留接口，后续启用。

### 7.5 动员

- 预备役：和平期不耗维护；战时动员 **3~5 回合**。
- 动员期间：地块产出 **-30%**；规模上限 = 地块人口 × 系数。

### 7.6 将领 / 情报 / AI 个性

- 将领：平庸 ×1.0 / 优秀 ×1.1 / 传奇 ×1.2；通过作战经验升级。
- 情报等级 1~5：影响秘密条约暴露、情报截获概率。
- AI 个性参数区间 0~1，由地图 / 难度预设分配。

## 8. 地图生成方案（Natural Earth）

1. **数据源**：Natural Earth `admin_0`（国界）+ `admin_1`（一级行政区）。
2. **流程**（`tools/mapgen`，Node 脚本，离线跑一次并提交产物）：
   - 选定欧洲区域的若干国家；
   - 合并 / 简化（简化容差保证形状美观）+ 投影（供 d3-geo）；
   - 将一级行政区**聚类**，使全图省份数达到目标（30 / 50 / 70）；
   - 指定 3 / 5 / 7 个**可玩国家**（各 5~6 省），其余省为**空白未占领区**；
   - 计算相邻关系、地形分类、基础资源，输出 `packages/map-data/*.json`。
3. 📌 待定：可玩国家名单与区域范围。

## 9. 美术与表现

- **主视图**：政治地图（按归属填色）+ 写实地形底纹（程序化生成的高度 / 地形色带 + 可选 AI 贴图）。
- 省份填充色 = 国家色（空白区为中性灰绿），叠加地形纹理、边界描边、首都 / 要塞 / 机场图标。
- 预留**图层切换**：政治 / 地形 / 补给 / 外交关系，便于扩展。

## 附录 A：M1 回合结算实现细则（实现前确认稿）

> §6.1 给出了结算**步骤**，本节给出每步的**精确执行顺序**与 M1 阶段的简化取舍。
> 原则：**确定性**（同一状态 + 同一指令 = 同一结果，不引入随机）+ 便于 M2 替换为战斗结算。

### A.1 结算顺序（`endTurn`）
1. 复制当前状态（纯函数，便于存档 / 回放 / 撤销）。
2. **移动与冲突裁决**（§A.2）。
3. **占领与抵抗**（§A.3）。
4. **抵抗值衰减**（§A.4）。
5. **资源产出与维护费**（§A.5）。
6. 回合数 +1，单位 `movedThisTurn` 清零，写入日志。

### A.2 移动与冲突裁决（M1 简化版）
- **合法性**：目标地块必须与出发地块相邻、且为陆地（海军 / 跨海属 M4）；陆军每回合 1 格。
- **驻军容量**：单地块最多 2 个单位，超出则退回出发地。
- **驻守者定义**：本回合**未下移动指令**的单位即视为驻守者。
- 逐目标地块裁决：
  1. 若目标地块存在**他国驻守者** → 所有进攻单位**退回出发地**（M2 起改为战斗结算）。
  2. 否则，把到达该地块的单位按「**当前战力 ↓，单位 id ↑**」排序（保证确定性）：
     - 首个单位进入；其后**同国**单位在容量允许内进入；
     - **他国**单位的移动一律退回（地块已被占据，形成对峙）。
  3. **互相交换地块**（A 从 X 打 Y、B 从 Y 打 X）：双方均为移动单位，各自出发地不再有驻守者，因此自然完成交换——无需特例。
- 每条被退回 / 被阻挡的移动都会写入战报日志。

### A.3 占领与抵抗
- 移动结束后，遍历每块地：若其中**只有某一个国家的单位**且该地不属于它：
  - 无归属（空白未占领区）→ 立即占领，`抵抗值 = 人口 × 0.5`。
  - 原属他国 → 占领，`抵抗值 = 人口 × 0.5 + 关系惩罚`（关系 ≤ -60 时 +30，其余 0）。
  - 写入日志「XX 占领了 YY」。
- `抵抗值 < 10` 视为**正式吞并**（日志提示；附加效果留待 M6）。

### A.4 抵抗值衰减
- 每回合 `抵抗值 -= 该地块驻军总战力 × 0.2`（下限 0）。

### A.5 资源产出与维护
- 产出：己方每块地按其 `base` 产出；首都资金 ×1.5；核心资源区已在数据中 ×3。
- 维护：本国所有单位的 `upkeep`（资金 / 石油 / 粮食）。
- 结算后资源**不允许为负**（不足则归零并记录日志；"经济崩溃"等惩罚规则留待 M6）。

## 附录 B：M2 合兵 / 分兵 / 战斗实现细则（实现后补充，📌 第 5 条待你确认）

### B.1 兵团改为「兵力堆叠」
- 单位不再固定为 100，而是携带**兵力值**（当前战力）。同一地块内、**同一国家 + 同一兵种**的单位在结算时**自动合并**为 1 支，兵力相加。
- 合并后士气按**兵力加权平均**。
- **地块驻军上限 = 200 兵力**（对应《玩法规则》"单地块最多 2 个满编陆军军团"），超出的移动会被拒绝并写入战报。

### B.2 分兵（按住 Ctrl，内联分兵框，不阻塞操作）
- 选中军团后，**按住 Ctrl** → 该兵团旁出现**内联分兵框** `[当前设定/上限]`（如 `100/200`）；
  - 右侧 **▲▼** 按钮增加/减少；
  - 鼠标移到框上**滚轮上下**调节（上滚增加、下滚减少）；
  - 每次调节 **50 一档**；松开 Ctrl 即隐藏，不影响任何其它操作（无阻塞弹窗）。
- 保持 Ctrl 再点击目标地块 = 按设定数量派出；不按 Ctrl 点击 = 整建制行动。
- 攻击时上限 = 当前兵力；进入己方地块时上限还受剩余驻军空间（200 − 现有己方兵力）限制。
- 若整建制放不下（且非进攻），会**自动**改为派得下的最大 50 倍数并在面板提示（不会弹窗打断）。

### B.3 移动 / 进攻 / 冲突裁决（在附录 A 基础上的扩充）
1. **正在移动的部队视为已离开出发地**（否则互相换防会被误判为战斗），因此"交换地块"可同时成立。
2. 目标地块**无敌方驻军** → 直接进入（受驻军上限约束）。
3. 目标地块**有敌方驻军** → **战斗结算**（§B.4）。
4. 多个国家的部队进入同一地块：按「兵力 ↓，单位 id ↑」确定性排序，逐个处理（先到者占据，后到者转为进攻）。

### B.4 战斗结算（复用《战斗结算公式与数值规则》）
```
最终战力 = 当前兵力 × 补给修正 × 制空修正 × 士气修正 × 将领修正
          (守方额外 × 地形修正 × 要塞修正；攻方额外 × 包围修正)
攻方战损率 = 守方最终战力 / (攻方最终战力 + 守方最终战力) × 0.3
守方战损率 = 攻方最终战力 / (攻方最终战力 + 守方最终战力) × 0.3
实际战损   = 本方参战兵力 × 本方战损率
```
- **制空修正**（需空军，M4）与**包围修正**（包围判定未实现）暂按 **×1.0** 占位，接口已留。
- **士气修正**：按文档给出的 4 个锚点（100→1.1 / 70→1.0 / 40→0.8 / 20→0.5）**线性插值**。
